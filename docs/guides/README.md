# Pillar-43 guides

For Lantern Wharf Editions staff and other press staff. Plain language, numbered steps,
what you should see after each step.

| Guide | For | Read it when |
|---|---|---|
| [install.md](install.md) | whoever sets up the Mac | first |
| [permissions.md](permissions.md) | staff who receive signed forms | a contributor signs |
| [archivist.md](archivist.md) | the archivist | bringing documents in |
| [maintenance.md](maintenance.md) | whoever looks after the Mac | updating, backing up, something broken |
| [workshop.md](workshop.md) | a facilitator | running a workshop with another press |

Forms to print: [../templates/](../templates/README.md).

[install-verification.md](install-verification.md) is the record of the commands
run on a fresh copy to check the install guide. It is for the developer, not for staff.

Several steps still need the Terminal because the screens do not exist yet. The
guides say which. **[the maintainer]** is the contact in each.
