# Dependency set for the native macOS app.
#
# This exists because the desktop bundle is a SUBSET of the server's
# dependencies, and until 2026-08-19 that subset was expressed as PyInstaller
# `--exclude-module` flags. Dropping PyInstaller dropped the exclusions with it:
# a plain `pip install -r requirements.txt` would silently re-enable the local
# Whisper path and add ~51MB of `av`/`ctranslate2` to every bundle. An
# exclusion that lives in a build flag is invisible the moment the build
# changes, so it lives here instead, where it is a line you can read.
#
# KEEP IN SYNC with api/requirements.txt. This file deliberately does NOT use
# `-r requirements.txt` + overrides, because pip has no "uninstall this one"
# directive — the whole list is restated so a drift is visible in review rather
# than inferred.
#
# Deliberately omitted vs api/requirements.txt:
#   faster-whisper  — local transcription. Needs ffmpeg, which the bundle does
#                     not ship (see the header of scripts/build-desktop.sh),
#                     and pulls ctranslate2 + av for ~51MB. The
#                     OpenAI-compatible Whisper path still works and
#                     services/capabilities.py reports the gap honestly.
